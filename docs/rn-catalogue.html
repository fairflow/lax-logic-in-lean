The fragment

RN(◯,{}) is the set of closed (atom-free) PLL formulas, quotiented by interderivability in LaxND. Write Γ ⊢ φ for PLL derivability and Γ ⊬ φ for its refutation.

Interd φ ψ := [φ] ⊢ ψ and [ψ] ⊢ φLaxLogic/Interd.lean:27

The order on classes is [φ] ≤ [ψ] ⟺ [φ] ⊢ ψ; strict order <, covering relation ⋖. The covering relation is written only in scoped form, a ⋖[K] b relative to a named finite set K:

a ⋖[K] b := a < b and ∀ c ∈ K. ¬(a < c < b)

No unscoped cover of RN(◯,{}) is proved, and none can be settled by search: RN(◯,{}) is infinite, so ruling out every interposer is a statement about an infinite set. A scoped cover is destroyed by enlarging K (placing eight further classes destroyed seven of twenty-one scoped covers).

Dictionary inclusion

Status is never a property of a formula alone. It is a property of a formula together with the representative set it is asked about. Fix a finite list of closed formulas R = (r₀, …, rn−1). Then the dictionary it determines is

D(R) := { [φ] : φ closed, ∃ k < n. Interd φ (r k) }

so membership and its negation are, as machine-checkable statements,

φ ∈ D(R) ⟺ ∃ k : Fin n. Interd φ (R k) φ ∉ D(R) ⟺ ∀ k : Fin n. ¬ Interd φ (R k)the shape of every refute_<cell> theorem

The second is the statement actually banked: each closure failure of round 2 is a sorry-free theorem refute_<cell> : ∀ k : Fin 16, ¬ Interd (combination) (rep2 k), universally quantified over all sixteen representatives — strictly stronger than a per-candidate refutation. That is what the tables mark ∉D.

Verdict vocabulary

Three verdicts, kept rigidly apart everywhere on this page.

verdictmeaningevidence
PROVED the stated collapse holds a sorry-free Lean term, axioms pinned
REFUTED · ∉D the combination is interderivable with no representative a kernel-checked finite countermodel per candidate, ∀ k, ¬ Interd …
OPEN · ? neither settled none — a sorry ASSERTS, so open status lives in data, never in a declaration

A further distinction, used only in the round-1 table: a cell can be refuted at its first candidate but still open, because refuting the stated collapse eliminates one candidate from a shortlist, not the whole shortlist. Those are marked ? in italic.

Engine-certified is not kernel-checked. The extension probe runs on sound engines (confluent-battery separation for ⊬, the G4c oracle and the LJF◯ ladder for ⊢). Its verdicts carry certificates, and those certificates are kernel-escalatable, but until a verdict is banked it is a computation, not a theorem. The probe sections say which is which.

Both dictionaries fail, and the failure is the result

Regularities of the order, as recorded

From docs/rho-structure.md. Writing a := ◯⊥, b := ◯¬◯⊥.

  • Graded. Every cover edge spans one rank; rank profile 1-2-2-3-5-5-3-1, height 7.
  • Ten poset-join-irreducibles: ⊥, a, ¬a, ¬¬a, b, ρ12, ρ13, ρ14, ρ19, ρ20. Every one that is not a rail atom is an implication.
  • Two stacked cubes. The interval [ρ4, ρ18] is exactly 2³ on atoms {ρ6, ρ7, ρ14}, with its joins and meets certified as class identities.
  • Two generators. All 22 representatives are Heyting terms over {a, b}: exactly two applications of ◯ occur in the whole catalogue.
  • Local disjunction property. For x < u and y < u, u ⊢ x ∨ y ⟺ u ≡ x ∨ y. This turns every "is this hub join a new class?" into a single identity cell.

Poset lub is weaker than the class of the syntactic join, and the first draft of that note conflated them; the correction is dated 2026-08-25 in the source. Whether v ≡ ⋁(lower covers of v) is a separate question per node.

Exactly what is certified

The 22 catalogue classes are pairwise distinct, kernel-backed. The 17 are candidates, and each carries its own conditions:

  • each is distinct from all 22 modulo the open cells listed against it below — a candidate with a non-empty "open at" list is not yet known to be new;
  • they are pairwise distinct except at the 22 open candidate-pairs listed below, where neither direction is settled;
  • the grouping into 17 is an upper bound on distinctness: it quotients the 22 NEW verdicts by the 7 certified mutual derivabilities only. If an open pair later collapses, the count falls.

Two members have no open cell against the 22 at all, so each is unconditionally distinct from every catalogue class: class(ρ8 ∨ ρ20) — strictly above ρ10, strictly below ⊤ — and class(ρ10 ∧ ρ20) — strictly below ρ10, ρ20, ρ21, ⊤. (The round-2 note names only the first; the stream records both.) Both still have open cells against other candidates, so their place among the 17 is not settled. All probe verdicts are engine-certified, not yet banked as theorems.

The Rieger–Nishimura embedding

The substitution p ↦ ◯⊥ carries the one-variable Rieger–Nishimura rungs to pairwise non-interderivable closed formulas — in PLL and in PCLL, for every pair of rungs, not a finite initial segment.

rn 0 = ⊥, rn 1 = p, rn 2 = ¬p rn (2k+3) = rn (2k+1) ∨ rn (2k+2) rn (2k+4) = rn (2k+3) ⊃ rn (2k+1) t n := rn n [p := ◯⊥]wip/rnEmbed.lean:427-439
rn_pairwise_pll : i ≠ j → ¬ Interd (t i) (t j) rnSub_deriv_iff : t i ⊢ t j ⟺ T(i) ⊆ T(j) on the RN ladder framean order-isomorphism onto its image

Two consequences worth keeping apart. The embedding proves RN(◯,{}) has infinite height. And it is an order-isomorphism onto its image, with the same image order in PLL and PCLL: distribution's collapses do not touch the embedded ladder's arrows.

The families

Four shapes, each uniform in a level index k ≥ 1, each built over the embedded rungs. Together they prove RN(◯,{}) infinite in three independent ways: height, width, and depth.

c k = ◯t(2k+1) ascending chain g k = c k ⊃ t(2k+1) antichain r k = t(2k+4) ⊃ c k antichain, ◯-fixed ◯(g k) antichain w k = g k ∧ t(2k+4) zigzag: comparable only two levels apart Gmeet n = g 1 ∧ … ∧ g (n+1) strictly descending, no floor

c k — the ascending chain

chain_step_le : c k ⊢ c (k+1) chain_step_strict : c (k+1) ⊬ c k chain_up : j ≤ k → c j ⊢ c k chain_lt_strict : j < k → c k ⊬ c j chain_pairwise : j ≠ k → ¬ Interd (c j) (c k)wip/chainStrict.lean

It still holds good. Every step is proved and the strictness is uniform in k, not a finite check: the negative halves evaluate one infinite constraint model (the abyss lift of the RN ladder skeleton) through Skel.box_force and Skel.transfer, and land by Kripke soundness. Nothing in the 2026-08-25 material touches it.

Two of the four ◯-collapse laws are in fact statements about the first two rungs of this very chain: c 1 = ◯t3 ≡ ρ7 is cBox_4, and c 2 = ◯t5 ≡ q12 = ◯ρ6 together with ◯ρ9 ≡ ◯ρ6 is cBox_9. Far from collapsing the chain, they identify its low rungs. c 3 = ◯t7 = ◯q11 is the round-1 cell cBox_11, certified ∉D₁₅ and ∉D₁₆ — a new class, strictly above t7.

◯(g k) — one infinite antichain, not many small ones

The question asked of this page was whether ◯(g k) is "many families of size-3 antichains". It is not. The record carries one theorem, uniform in the indices:

bg_incomparable : k ≥ 2, j ≠ k → ◯(g j) ⊬ ◯(g k) bg_pairwise : j, k ≥ 2, j ≠ k → ¬ Interd (◯(g j)) (◯(g k))wip/families.lean:535, 558

So { ◯(g k) : k ≥ 2 } is a single ℕ-indexed antichain: infinitely many classes, pairwise incomparable, each off the image and not ⊤ (bg_off_image, bg_not_top, both for k ≥ 2). The "size 3" reading comes from the picture, not the theorem: the v17 diagram drew three levels of each family with a faded continuation stub, and put one amber bracket down the ◯g column. The bracket denotes the whole antichain; three of its members are drawn.

The one place the record really is incomplete

The uniform theorem needs k ≥ 2 on the target index only. So for k ≥ 2 we have ◯(g 1) ⊬ ◯(g k), but the converse cells ◯(g k) ⊢? ◯(g 1) are not covered by anything in the record. The certified antichain therefore starts at k = 2; whether ◯(g 1) joins it is open at exactly those cells. ◯(g 1) ≡ q13 = ◯ρ11 (bg_one_q13), which the round-2 probe independently reports as a new class.

Gmeet — the infinite descending ladder, and the missing floor

Gmeet 0 = g 1 Gmeet (n+1) = Gmeet n ∧ g (n+2) Gmeet_le : Gmeet (n+1) ⊢ Gmeet n Gmeet_strict : [Gmeet n] ⊬ Gmeet (n+1)wip/uiObstruct.lean:109 · wip/hunts.lean:112

The partial meets of the gap antichain descend strictly forever. The countermodel is the edged lift cmE (n+1), at whose edge world gaps 1 … n+1 are forced — hence Gmeet n — while g (n+2) fails. Every Gmeet n is closed and has ◯-depth ≤ 2 (depth_Gmeet).

The descent has no limit inside the logic:

gap_no_glb : the family { g k : k ≥ 1 } has NO greatest lower bound, quantified over ALL formulas L_no_greatest : its variable-free reading — the landing ideal has no greatest elementwip/floor.lean:489, 507

So RN(◯,{}) is not a complete lattice: this is the third independent sense in which it is infinite, alongside height (the ladder) and width (the gap antichain).

The depth-reducing laws, for reference

Class depth, not syntactic depth, is the invariant: DepthLe n A := ∃ B. Interd A B ∧ boxDepth B ≤ n.

◯⊤ ⊣⊢ ⊤ box_top no axioms ◯◯A ⊣⊢ ◯A box_idem no axioms ◯(A ∧ B) ⊣⊢ ◯A ∧ ◯B box_and [propext] ◯(A ⊃ ◯B) ⊣⊢ A ⊃ ◯B box_imp_box no axioms ◯(◯A ∨ ◯B) ⊣⊢ ◯(A ∨ B) box_or_box [propext]wip/depth.lean

The only depth-raising constructions are ◯ over a disjunction and ◯ over an implication whose consequent is not already boxed (depth_raising_only_or_imp). And ◯ over ∨ genuinely escapes: distr_4_3_not_derivable refutes ◯(t3 ∨ t4) ⊢ ◯t3 ∨ ◯t4.

The tables as a simplifier

Every certified cell is an oriented rewrite rule qi ⊙ qj ⟶ qk, so the table runs as a normaliser on any closed goal: congruence closure over facts already paid for. The claim, as stated in the record:

The claim under test

"These tables are now also a simplifier. Every certified cell is an oriented rewrite rule qi ⊙ qj ⟶ qk, so the whole table can be run as a normaliser on any closed goal — congruence closure over facts already paid for. Discrepancy found — "a floor of 15" is not supported

The record explains the nested figure by saying the floor is 15, "the dictionary's classes, which the ∧/∨ closure cannot leave". The ∧/∨ closure does leave the dictionary, and the repository's own certificates say so. Two of the corpus generators are q8 and q10, and

q8 ∧ q10 ∉ D₁₅ cAnd_8_10 refuted against the fifteen (it is q15) q8 ∨ q10 ∉ D₁₆ refute_cOr_8_10 : ∀ k : Fin 16, ¬ Interd (q8 ∨ q10) (rep2 k)

So 15 is neither a floor nor even an upper bound on the classes the corpus reaches. Two things are worth saying instead, and both are measured, not asserted.

25 is a certified upper bound. The normaliser collapsing two forms is a proof that they are interderivable (simplifyWith_interd), so the 3,996 trees carry at most 25 distinct classes.

14 is a certified lower bound. Running the ≤5-world mutually confluent battery over the 25 residual forms separates 268 of the 300 pairs; 32 pairs are left unresolved. The maximum set of forms that are pairwise separated has size 14 — computed exactly, not greedily.

What ≈39 classes does to the reading

The extension probe puts the catalogue at ≈39 classes at this ◯-depth (22 certified plus up to 17 candidates). That does not change any measured number above, because the corpus the simplifier is screened on is fixed: ten generators and their ∧/∨-trees. It does change what "the floor" could ever mean. The bound that matters for a probe is the one just measured — the number of distinct classes among the target cells' values, which is a property of the corpus, not of any catalogue. Quoting the catalogue's size as a floor conflates the two, and the size is now a moving number in any case.

The standing consequence for banking is unchanged and worth restating: recombination cannot settle a cell outside the congruence closure of the banked equations (rnextend: 0 of 87, control 237/237 in the same run). Only a new proof search or a larger countermodel can.
